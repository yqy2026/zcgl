# ADR-0025：记录外部合同审批证据，不建设第二套审批流

**状态**：accepted（2026-08-26；部分取代 ADR-0013）

全部合同继续在既有独立合同审批系统完成审批，本系统不建设提审、联审或路由 BPM，只保存审批系统、审批单号、结果、时间、证据、合同版本或内容哈希以及确认人。承租转租由运营方负责外部审批，代理直租由产权方负责外部审批；任一方可上传结果，审批责任单位确认其权威性。合同核心条款变化使原审批失效。该决策保留 ADR-0013“不在本系统建设审批引擎”的边界，但取代“补录即生效、无审批证据门”的结论。

## 后果

- 合同生效状态不能替代外部审批事实。
- 本系统没有审批任务路由，但必须阻止缺少有效外部审批证据的合同生效。
- 外部审批证据与最终盖章文件分别保存，上传人与权威确认人可以不同。
