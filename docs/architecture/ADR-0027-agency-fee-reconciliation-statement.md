# ADR-0027：盖章对账单确定代理费应收，开票与收款独立登记

**状态**：accepted（2026-08-26；2026-08-27 修订）

代理服务费以产权方逐笔确认的终端租金到账明细为试算基础，但试算不形成正式应收；只有双方在系统确认同一版本并上传双方盖章对账单后，代理费应收才成立。发票与产权方向运营方支付的代理费收款按真实发生时间独立登记，分别通过开票分摊和收付分配关联服务费结算项，不能从终端租金到账互相派生。该决策取代旧 `ServiceFeeLedger` 将应收和实收同时从直租租金台账派生的口径。

## 2026-08-27 修订

原决策将发票设为服务费付款前置，只允许“凭票请款”这一方向，无法同时支持“先收款后按期开票”或预收场景。P0 走查因此撤销该全局前置条件：合同或制度可以对开票时点形成待办、警告或例外审批，但系统不得以单向状态机阻止记录真实发票或资金事实。盖章对账单确定服务费应收、终端租金到账不派生服务费实收两项原裁决继续有效。

## 后果

- 对账单保存纳入的到账行、基数、比例、最终金额、双方确认、盖章文件和版本链。
- 更正追加后继对账单，不覆盖已经确认的对账事实。
- 终端租金到账、代理费应收、发票和代理费实收是四类不同事实。
- 发票行与服务费结算项、代理费实收与服务费结算项分别允许多对多分摊或分配；发票与资金不直接互相核销。
- 先票后款、先款后票、分次开票、分次收款、红冲和退款均须保留原事实与更正链。
