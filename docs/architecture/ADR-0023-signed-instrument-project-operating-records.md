# ADR-0023：签署文书与项目经营记录分离

**状态**：superseded by ADR-0028（2026-10-22）

同一份双方签署或盖章的合同、委托协议只有一个法律文书身份和版本链，可关联多个项目经营记录；每个项目经营记录独立承载账单、收付、催收和利润归属。共享扫描件不能代替法律文书身份，也不得通过同号项目合同副本反推补充协议、终止或续签关系。该决策保留每笔经营账款唯一归属项目的原则，同时取代 ADR-0012“各项目各建合同、只共享扫描件”的表达。

## 后果

- 签署文书的补充协议、终止、续租和版本链只维护一次。
- 项目经营记录冻结各自历史归属，文书变更按明确范围影响对应记录。
- 文件内容、合同号和项目记录均不能单独充当法律文书身份。
