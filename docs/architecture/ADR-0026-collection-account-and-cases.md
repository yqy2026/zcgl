# ADR-0026：欠费账户与催收案件分离

**状态**：superseded by ADR-0028（2026-10-22）

系统为每个 `Party × Project` 提供持续欠费账户视图，并为每次独立欠费周期建立新的催收案件；已关闭案件不因以后再次欠费而重开。逾期事实仍由账单到期日和未清金额派生，催收案件只承载责任人、下一动作、证据、承诺、升级和法务关联，不能修改财务结清状态。真实运营由运营方负责日常催收，因此首期纳入内部催收任务，但不自动向承租人外发消息。

## 后果

- ADR-0006 删除的旧 `CollectionRecord` 状态机不直接复活；新模型按账户和 episode 重新设计。
- 达到策略阈值自动生成内部任务，法务立案仍由有权人员确认。
- 合同关闭后未结欠费可继续由催收案件承接。
