# ADR-0024：终端合同必须验证并冻结出租授权

**状态**：superseded by ADR-0028（2026-10-22）

上游、下游、委托和直租标记继续用于收入与成本方向，但不能代替出租授权。承租转租的下游合同必须引用并验证有效上游承租及转租授权，代理直租合同必须引用有效委托授权；验证覆盖 Space、期间和用途，并在合同生效时冻结授权快照。来源后来失效形成授权缺陷，不静默改写已签合同。该决策取代 ADR-0003“不计算、不提示、不阻断主合同覆盖”的部分，但仍不恢复为利润计算服务的通用逐对合同配对表。

## 后果

- 缺少或覆盖不足的授权阻止新合同生效。
- 利润仍按合同方向和项目归属汇总，不要求人为维护任意上下游配对。
- 授权来源和历史快照成为合同生效事务的一部分。
