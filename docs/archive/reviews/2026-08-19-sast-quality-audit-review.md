## 已验证安全基线（抽样校准，非问题项）

以下经逐行核实为安全/正确实现，后续改动不应回退：

- **鉴权覆盖**：api/v1 全部 39 个路由文件仅 4 个无鉴权端点且均属预期（login/refresh/两个只读 health）。
- **BOLA 防护**：contracts/assets/party/产权证详情端点全带 `require_authz` 且 trusted context 以 DB 加载优先合并，客户端无法伪造归属；列表数据范围 fail-closed（空 party_ids 注入 `false()`）。
- **排序/过滤注入**：客户端排序字段强制白名单（query_builder + field_whitelist 三套白名单 + blocked_fields），非白名单抛 InvalidRequestError。
- **上传链**：流式限大小、魔数签名、PDF 加密/页数校验、XLSX zip 炸弹/宏防御、`resolve().relative_to(root)` 防穿越；无 StaticFiles 挂载（uploads 不可目录遍历）。
- **前端**：无 `dangerouslySetInnerHTML`/`innerHTML`/`eval`，token 全程 httpOnly cookie，登出清理彻底，401 刷新防循环，CSRF 双提交校验（login 豁免）。
- **密钥/配置**：`SECRET_KEY` 必填 min_length=32，弱密钥生产拒绝启动；CORS 显式拒绝 `*`。
- **git 历史**：全历史从未提交 .env/.pem/.key。
- **依赖**：双 lockfile 冻结、无 git/fork 直连依赖、pnpm overrides 全为安全版本上浮。
- **并发正确面**：资产乐观锁真实生效（version 列 + 8 处 StaleDataError→409 映射）；解析会话状态机用 Redis Lua CAS 原子转换；每请求一 session + `expire_on_commit=False`（无 MissingGreenlet 温床）；快照类缓存（权限/决策值均为 dict/list 标量）无 ORM 直序列化。
- **分层纪律**：api 层零直接查库且有专项 layering 测试守卫。
