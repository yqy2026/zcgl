日期：2026-11-03。产品规则见 [PRD](../../prd.md)，字段见 [ContractSupplement](../../specs/domain-model.md#4251-contractsupplement)，接口见 [档案契约](../../specs/api-contract.md#512-档案)。本记录是本地工作树证据，不代表已合并或部署。

## 交付与边界

补充协议按父合同登记编号、名称和可选签署日期；档案权限可登记或带原因/版本撤回，只读账号可查历史。编号在父合同内唯一，撤回后也不复用。撤回保存原记录和审计，不删除文件或改变合同条款、租金、覆盖及报送快照。

矩阵只从当前有效父合同的未撤回登记计应有，同一协议跨物业总览去重。已有文件依据独立档案目标及正确附件归属，版本不放大份数。无登记时应有为 0、完成率为 null；补充协议不再显示登记清单待接入。文件上传/替换/下载维护本轮仍未扩展到该对象，页面明确提示仅登记清单。

后端和前端分工实现，第三个只读子任务复核。复核发现并采纳：撤回写操作移入 CRUD，数据库 CHECK 明确拒绝 NULL 原因，避免 SQL 三值逻辑放过不完整历史。复核曾基于旧快照认为没有重载入口，重读当前源码后撤回该结论；现有页面提供始终可见的重载按钮。
