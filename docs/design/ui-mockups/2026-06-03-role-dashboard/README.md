# 角色化工作台 HTML 原型

## 定位

本目录存放角色化工作台方案的静态 HTML 原型，用于产品、设计和研发讨论领导、资产管理、招商、物业运维四类岗位的首页体验。

关联方案：[`../../role-based-dashboard-redesign.md`](../../role-based-dashboard-redesign.md)

## 文件清单

| 文件 | 用途 |
|---|---|
| `prototype-dashboard.html` | 初版工作台原型，展示资产运营管理系统首页布局方向 |
| `prototype-dashboard-v2.html` | v2 角色视角原型，支持在页面顶部切换不同岗位视角 |

## 使用方式

直接用浏览器打开 HTML 文件即可查看。该原型只作为设计讨论材料，不是生产前端入口。
