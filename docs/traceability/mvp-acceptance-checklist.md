本文档是 PRD §3.1（MVP 一票否决目标）与 §9（放量前验收标准）的**执行追踪表**，回答"放量前还差哪些验收"。

- 验收依据与口径：`docs/prd.md` §3.1 / §3.2 / §9。

## 5. 状态流转规则

- ⏳ 待验收 → 🟡 工程通过：工程侧证据齐全（`make check` 门禁全绿 + 真实 API/GUI 实测 + 测试证据），由验收执行方登记，备注写明验证时间与方式。
