# 需求追踪

本目录存放需求到实现和测试证据的追踪信息。

| 文档 | 用途 |
|---|---|
| [requirements-trace.md](requirements-trace.md) | REQ 到产品状态、实现状态、代码证据、测试证据的映射 |
| [mvp-acceptance-checklist.md](mvp-acceptance-checklist.md) | 资产运营 v5 MVP 放量前验收清单（PRD §9 G1–G7 与 ACC-V5 边界场景） |

维护规则：

- 产品状态和实现状态分开记录。
- 代码路径和测试路径只放在本目录，不放入 PRD。
- 路径必须真实存在，后续由 docs-lint 校验。
