# P0 原型走查清单（运营管理方用）

**走查对象**：`frontend/prototype/redesign-ia.html`（双击打开即可，无需安装、不写任何数据）
**走查依据**：`docs/plans/2026-08-26-land-property-v4-implementation.md`（含 2026-08-27 ISS-02/03/05 修订）
**进入方式**：首屏为登录页，9 张身份卡点选即进入；顶栏「走查路线」下拉可一键跳到每条路线并**自动切换岗位**。
**预计时长**：完整 9 条约 40–60 分钟；只看三项修订核心（②③⑥）约 20 分钟。

> 走查重点（方案 §5-P0-3）：岗位入口、页面任务、状态文案、阻断原因、产权方协作边界、账款操作顺序。
> 页面中「模拟：」按钮均为原型代为点亮，正式系统按岗位鉴权放行；除模拟操作外不提供任何「补录即生效」路径。

## ① 登记意向与条件审议（岗位：招商运营）

| 项 | 内容 |
|---|---|
| 操作 | 登录页选「招商运营」→ 左侧「租赁意向」→「＋登记租赁意向」新建一张卡（拟租租金填 0.20 · 低于底价 0.38）→「开始条件审议」→「去决议」→ 先**空理由提交（应被拦截）**→ 选「接受」并填理由 |
| 预期 | 多家可并行在谈、同一空间不锁定（吕巨建受限空间卡只显示暂停说明、无决议按钮）；结论只有接受/反提/拒绝且理由留痕；**低于底价的接受不禁用**，但决议模态明示例外审批前生效门保持红色阻断；已接受卡「拟定合同 →」直达生效页并携带来源意向 |
| 条款 | §3.2.1–3；红线：无正式报价对象、无 Space Lock |

## ② 拟定合同并生效（岗位：招商运营）—— ISS-05 修订重点

| 项 | 内容 |
|---|---|
| 操作 | 走查路线② → 右侧生效检查**自动出结果**（无逐项点击）→ 点折叠头展开通过项证据 → 左侧修正两个冲突字段（主体二选一、保证金二选一）→ 逐项消除阻断（审批证据 / 国资材料 / 盖章文件用「模拟：」按钮；前置条件走「查看工单」或授权岗留痕豁免）→「提交生效确认」→ 确认摘要 → 已生效 |
| 预期 | 阻断/无法判定置顶且各有下一动作；通过项默认折叠但显示**数量、规则集版本、检查时间**，可展开证据；金额双口径不一致阻止生效、修正后自动重检；**缺失输入显示「无法判定」不静默放行**（切吴俊锋车位案例看 P118 授权期限缺失）；提交后一次保存：合同生效＋授权快照冻结＋审批证据绑定＋首批账单（同事务）；页底「近期被阻止的生效尝试」演示权属审查不足（晓南车场无证）阻断、并发后提交者失败 |
| 条款 | §3.2.4–15（重点 11–14） |
| 进阶 | 走查「权属与授权」批准 EX-2026-03 → 回本页池玉銮案例：底价门转「已批准例外」→ 点「模拟：生效前修改租金至 ¥0.30（重算）」→ **原结果失效、重新计算、重新阻断**（必测场景 14） |

## ③ 到账认领与分配（岗位：出纳 → 财务复核）—— ISS-03 修订重点

| 项 | 内容 |
|---|---|
| 操作 | 走查路线③ → 看统计卡与规则优先级说明 → 勾选 3 笔待复核拟分配（含一笔金额守恒 4×¥18,400 集合）→「批量复核入账」→ 看「今日已核销」11→14 笔 → 逐条看异常池 6 笔 → 看「已到账待核销 ≠ 已核销」卡 |
| 预期 | **无逐笔五步**：高置信唯一匹配自动形成拟分配，每笔留存命中规则、候选集合、规则版本；批量一次生效，**只有复核生效才派生「已核销」并生成经营流水**；待核销**不减少应收未结**，唯一结算项 SLA 内暂停催缴、超时恢复；异常池（无附言/多候选/超额/代付/主体不明）不自动分配，代付须留证明，**人工拟分配提交人不得自审**；超额转未分配预收、不自动冲抵未来账单 |
| 条款 | §3.5.1–8；必测场景 12/13 |

## ④ 欠费催收（岗位：催收运营）

| 项 | 内容 |
|---|---|
| 操作 | 走查路线④ → 左「欠费账户（客户×项目）」右「独立案件」→ 给凤凰创意新欠案件选择责任人分派 → 看明察企业时间线 → 押金抵扣→坏账核销顺序闭环（先抵扣 ¥95,700 → 余额 ¥1,246,458 → 核销申请） |

| 条款 | §3.7；§3.5.11 |

| 条款 | §3.6.1–2；§3.8.3–4 |

## ⑥ 代理费对账单定案（岗位：财务复核）—— ISS-02 修订重点

| 项 | 内容 |
|---|---|
| 操作 | 走查路线⑥ →「模拟：产权方在线确认」→「上传双方盖章扫描件」→ 确认摘要 → 应收成立 → **任意顺序**点「登记服务费发票（开票轨）」与「登记服务费收款（资金轨）」→ 看双轨面板 → 看 STMT-2026-Q1「先收款 · 后开票」对照卡 |
| 预期 | 盖章前都只是试算；**双方盖章后服务费应收才成立**；此后开票轨（开票分摊）与资金轨（收付分配）按真实发生顺序**独立登记、互不前置**——凭票请款（先票后款）与先收款后开票均可流转；未结金额只由有效收付分配派生；对账单不保存可改写的累计开票/实收；更正走版本链（STMT-2025-Q4）不覆盖原单 |
