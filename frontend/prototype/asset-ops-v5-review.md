## 三、产品决定（2026-10-22）

1. **领导只读视角：不做。** 系统只有资产管理岗一个角色。
2. **多人分项目负责：不做。**
3. **上游尚未录入的终端合同：宗按物业计算。** 单元有在租终端合同即算已出租，与是否挂上游无关。列表上游列显示黄字“未录入”（原型示例数据里暂无此类合同，按 README 实现）。
4. **数据导入支持“更新已有”。** 已加入原型：数据导入页顶部切到“更新已有数据”。

至此没有待定事项。
