## 当前基线：asset-ops-v5.html

- `asset-ops-v5.html`：资产管理岗 v5 可点击原型，依赖同目录 `support.js`。

运行时建议通过本地静态服务器打开 `asset-ops-v5.html`，避免浏览器对 `file://` 同目录脚本的限制。交互状态仅保存在浏览器 `localStorage` 的 `assetops-v5` 键中，清除该键可恢复初始数据。

权威顺序：PRD/领域模型/API 契约定义业务和字段；本目录定义布局、文案和交互参考。示例数据和原型逻辑不得作为生产数据结构直接复制。
